# Unemployment Analysis with Python

## Project Overview

This project focuses on analyzing unemployment trends in India using Python and data visualization techniques.

The project was completed as part of the Oasis Infobyte Data Science Internship.

## Objective

The main objective of this project is to explore unemployment patterns across different regions of India and understand how unemployment rates change over time.

## Dataset

The project uses the Unemployment in India dataset.

The dataset contains information such as:

- Region
- Date
- Frequency
- Estimated Unemployment Rate
- Estimated Employed
- Estimated Labour Participation Rate

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Workflow

1. Loaded and inspected the dataset.
2. Checked the dataset structure and data types.
3. Identified missing values.
4. Cleaned and prepared the data.
5. Converted date values into the appropriate format.
6. Analyzed unemployment rates across regions.
7. Studied unemployment trends over time.
8. Created visualizations to understand the data.

## Exploratory Data Analysis

The analysis includes:

- Region-wise average unemployment rate
- Month-wise unemployment trends
- State-wise unemployment comparison
- Time-series visualization
- Bar charts for regional comparisons

## Visualizations

The project uses charts to present unemployment patterns and make the findings easier to understand.

## Conclusion

This project helped me gain practical experience in data cleaning, exploratory data analysis, time-series analysis, and data visualization.

It also provided insights into how Python can be used to study employment-related data.
